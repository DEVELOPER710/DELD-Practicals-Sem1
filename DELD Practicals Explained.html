Experiment 2Implementation of basic logic gates using universal gates: NAND and NOR

Circuit diagram

Aim

To implement the basic logic gates (NOT, AND, OR, NAND, NOR, XOR and XNOR) using only the universal gates NAND and NOR, and verify their truth tables.

Apparatus

Digital IC trainer kit, +5 V DC supply, connecting (patch) wires and the following ICs:

IC list: ICs required for this experiment

ICDescriptionUsed forQty
IC 7400Quad 2-input NAND gateAll gates realised with NAND1
IC 7402Quad 2-input NOR gateAll gates realised with NOR1

Theory

A universal gate is a gate from which every other logic gate can be built. NAND and NOR are universal gates.

  • NAND = NOT of AND: Y = A·B. Output is 0 only when all inputs are 1.
  • NOR = NOT of OR: Y = A+B. Output is 1 only when all inputs are 0.
  • Tying both inputs of a NAND (or NOR) together gives a NOT gate: A·A = A.
  • AND = NAND followed by NOT; OR = NOT the inputs, then NAND (A·B = A + B, by De Morgan).

Experiment 3Verification of De Morgan's laws and implementation of Boolean expressions using logic gates

Circuit diagram

Aim

To verify De Morgan's theorems using logic gates and to simplify and implement Boolean expressions using Boolean laws.

Apparatus

Digital IC trainer kit, +5 V DC supply, connecting (patch) wires and the following ICs:

IC list: ICs required for this experiment

ICDescriptionUsed forQty
IC 7400Quad 2-input NAND gateA·B (LHS of law 2)1
IC 7402Quad 2-input NOR gateA+B (LHS of law 1)1
IC 7404Hex inverter (NOT gate)A, B1
IC 7408Quad 2-input AND gateA·B (RHS of law 1)1
IC 7432Quad 2-input OR gateA+B (RHS of law 2)1

Theory

De Morgan's first law: the complement of a sum equals the product of the complements: A + B = A · B. A NOR gate is the same as an AND gate with bubbled (inverted) inputs.

De Morgan's second law: the complement of a product equals the sum of the complements: A · B = A + B. A NAND gate is the same as an OR gate with bubbled inputs.

Each law is verified by building the LHS and the RHS as separate circuits and checking that both outputs match for every input combination.

Boolean laws used for simplification: Identity (A·1 = A, A+0 = A), Null (A·0 = 0, A+1 = 1), Idempotent (A·A = A, A+A = A), Inverse (A·A = 0, A+A = 1), Commutative, Associative, Distributive (A(B+C) = AB+AC, A+BC = (A+B)(A+C)).

Example 1: AB + AB + AB + BC = B(A+A) + AB + BC = B + AB + BC = B(1+C) + AB = B + AB = A + B

Example 2: AB + A + B + CC = AB + A + B = AB + AB = A(B+B) = A

Number of ICs used: 5 — 7400, 7402, 7404, 7408 and 7432 (one each).

Theory

An adder is a combinational circuit that adds binary numbers.

Half adder: adds two 1-bit inputs A and B and gives a Sum (S) and a Carry (C). It cannot accept a carry from a previous stage.
S = A ⊕ B    C = A · B
It uses 1 XOR gate and 1 AND gate.

Full adder: adds three 1-bit inputs A, B and the carry-in Cin, giving Sum and Carry-out.
S = A ⊕ B ⊕ Cin    Cout = AB + (A ⊕ B)Cin
It is built from two half adders and an OR gate: 2 XOR, 2 AND and 1 OR gate.

Number of ICs used: 3 — IC 7486 (XOR), IC 7408 (AND) and IC 7432 (OR). The half adder alone needs 2 ICs (7486 and 7408).

Experiment 6Design and realization of multiplexer and demultiplexer circuits using only 2-input NAND gates

Circuit diagram

Aim

To design and realize a 2:1 multiplexer and a 1:2 demultiplexer using only 2-input NAND gates.

Apparatus

Digital IC trainer kit, +5 V DC supply, connecting (patch) wires and the following ICs:

IC list: ICs required for this experiment

ICDescriptionUsed forQty
IC 7400Quad 2-input NAND gateAll NAND gates (4 for MUX, 5 for DEMUX)2

Theory

A multiplexer (MUX) is a data selector: it has 2n data inputs, n select lines and one output. The select lines decide which input is connected to the output. For a 2:1 MUX:
Y = S·I0 + S·I1  (S = 0 → Y = I0; S = 1 → Y = I1)

MUX with NAND gates: G1 = NAND(S, S) = S; G2 = NAND(I0, S); G3 = NAND(I1, S); G4 = NAND(G2, G3) = SI0 + SI1. That is 4 NAND gates = one IC 7400.

A demultiplexer (DEMUX) is a data distributor: one data input D, n select lines and 2n outputs. The select lines decide which output receives D. For a 1:2 DEMUX:
A = S·D    B = S·D

DEMUX with NAND gates: G1 = NAND(S, S) = S; G2 = NAND(S, D); G3 = NAND(G2, G2) = SD; G4 = NAND(S, D); G5 = NAND(G4, G4) = SD. That is 5 NAND gates, which needs two 7400 ICs (4 gates each).

Number of ICs used: 2 — IC 7400 ×2. The 2:1 MUX uses 4 NAND gates (one 7400); the 1:2 DEMUX uses 5 NAND gates, so it needs both 7400 ICs. The two circuits are wired one after the other.

Experiment 7Design and implementation of simple encoder and decoder circuits

Circuit diagram

Aim

To design and implement a 4:2 encoder and a 2:4 decoder using logic gates and verify their truth tables.

Apparatus

Digital IC trainer kit, +5 V DC supply, connecting (patch) wires and the following ICs:

IC list: ICs required for this experiment

ICDescriptionUsed forQty
IC 7432Quad 2-input OR gate2 OR gates (encoder)1
IC 7408Quad 2-input AND gate1 AND gate: Y1·Y2 (encoder)1
IC 7404Hex inverter (NOT gate)NOT gates: Y2 (encoder); A, B (decoder)1
IC 7411Triple 3-input AND gate3-input AND gates: A, B, EN (decoder)2

Theory

An encoder converts 2N input lines into an N-bit binary code. A 4:2 encoder has inputs Y0–Y3 and outputs A1, A0.

This is a priority encoder: if more than one input is high, the highest-numbered input wins and the lower ones are ignored. In the truth table, X (don't care) on an input means its value does not change the output: once a higher input is 1, the lower inputs can be 0 or 1.

A1 = Y2 + Y3    A0 = Y3 + Y1·Y2
A1 is 1 when Y2 or Y3 is active. A0 is 1 when Y3 is active, or when Y1 is active and the higher input Y2 is not. (Y0 needs no gate: when only Y0 is high the output is 00.)

The encoder needs 1 NOT gate (Y2), 1 AND gate (Y1·Y2) and 2 OR gates.

A decoder does the reverse: it converts an N-bit input into 2N outputs, and exactly one output goes high for each input combination. A 2:4 decoder with enable (EN):
Y0 = EN·AB   Y1 = EN·AB   Y2 = EN·AB   Y3 = EN·AB
It needs 2 NOT gates and 4 three-input AND gates. When EN = 0, all outputs are 0.

Number of ICs used: 5 — 7432, 7408, 7404 and two 7411. Encoder: 7432 (2 OR), 7408 (1 AND), 7404 (1 NOT). Decoder: 7404 (2 NOT, same IC as the encoder) and two 7411 (four 3-input AND gates, three per IC).

Experiment 8Design and realization of RS and JK flip-flops using logic gates

Circuit diagram

Aim

To design and realize the RS (SR) and JK flip-flops using logic gates and verify their truth tables.

Apparatus

Digital IC trainer kit, +5 V DC supply, connecting (patch) wires and the following ICs:

IC list: ICs required for this experiment

ICDescriptionUsed forQty
IC 7400Quad 2-input NAND gate4 NAND gates for RS; 2 NAND gates (latch) for JK1
IC 7410Triple 3-input NAND gate3-input NAND gates for JK inputs1

Theory

A flip-flop is a sequential circuit that stores one bit. Its output depends on the present inputs and on the previous output (Qn). A clock (CLK) decides when the inputs take effect.

RS flip-flop: two NAND gates gate S and R with the clock, and two cross-coupled NAND gates form the SR latch. S = 1 sets Q to 1, R = 1 resets Q to 0, S = R = 0 holds the previous state, and S = R = 1 is forbidden (Q and Q would both become 1). Characteristic equation: Qn+1 = S + RQn (with SR = 0).

JK flip-flop: removes the forbidden state of RS. Q is fed back to the K gate and Q to the J gate, so J = K = 1 toggles the output. Characteristic equation: Qn+1 = JQn + KQn. A long clock pulse with J = K = 1 causes the race-around condition, which a master-slave JK flip-flop removes.

Number of ICs used: 2 — RS flip-flop: 1 IC (7400, all 4 gates). JK flip-flop: 2 ICs (7410 for the two 3-input NAND gates, 7400 for the latch).

Theory

D (Data/Delay) flip-flop: an SR flip-flop with S = D and R = D through a NOT gate, so S and R can never both be 1 and the forbidden state disappears. On the clock pulse the output follows the input.
Qn+1 = D
Used in registers and for storing one bit.

T (Toggle) flip-flop: made by feeding T ⊕ Q into the D input of a D flip-flop. When T = 0 the output holds; when T = 1 it toggles (changes state) on every clock pulse.
Qn+1 = T ⊕ Qn = TQn + TQn
Used in counters and frequency dividers.

Number of ICs used: 3 — D flip-flop: 2 ICs (7404 + 7400). T flip-flop: 3 ICs (7486 + 7404 + 7400).

Experiment 10Simplification of Boolean expressions using Karnaugh maps and implementation using logic gates

Circuit diagram

Aim

To simplify the Boolean expression F = Σm(9, 10, 11, 12, 13, 14, 15) using a Karnaugh map and implement it using NAND gates.

Apparatus

Digital IC trainer kit, +5 V DC supply, connecting (patch) wires and the following ICs:

IC list: ICs required for this experiment

ICDescriptionUsed forQty
IC 7400Quad 2-input NAND gate6 NAND gates2

Theory

A Karnaugh map (K-map) is a grid of 2n cells, one per minterm, arranged in Gray-code order (00, 01, 11, 10) so that adjacent cells differ in only one variable. Grouping adjacent 1s removes the variable that changes, which simplifies the expression.

Grouping rules: groups must contain 1, 2, 4, 8 or 16 cells; make groups as large as possible; groups may overlap and wrap around the edges; every 1 must be covered; use the fewest groups.

Given: F = ABCD + ABCD + ABCD + ABCD + ABCD + ABCD + ABCD = Σm(9, 10, 11, 12, 13, 14, 15)

Groups (quads): row AB = 11 (m12, 13, 15, 14) → AB; column CD = 01 and 11 in rows 11, 10 (m13, 15, 9, 11) → AD; columns CD = 11 and 10 in rows 11, 10 (m15, 14, 11, 10) → AC.

F = AB + AC + AD = A(B + C + D)

NAND implementation: G1 = AB, G2 = AC, G3 = AD; G4 = NAND(G1, G2) = AB + AC; G5 = NAND(G4, G4) = AB + AC; G6 = NAND(G5, G3) = AB + AC + AD. That is 6 NAND gates.

Number of ICs used: 2 — IC 7400 ×2 (6 NAND gates, 4 per IC).

Experiment 11Design of a combinational logic circuit using two-input basic gates and analysis of its output

Circuit diagram

Aim

To design the given combinational logic circuit using two-input basic gates, obtain its truth table and check, using a K-map, whether it can be simplified further.

Apparatus

Theory

A combinational circuit is one whose output depends only on its present inputs (no memory). Its behaviour is analysed by writing the output of each gate step by step and then the final expression.

Gate-by-gate analysis of the given circuit:

  • OR gate (C, D) → C + D, then NOT → C + D

Z = 1 for minterms Σm(0, 1, 3, 6, 7, 8, 10, 13).
